# 💊 BestCord Manager

![GitHub Workflow Status (with event)](https://img.shields.io/github/actions/workflow/status/BestCord-DiscordClient/revenge-manager/release.yml)
![Open Software License 3](https://img.shields.io/badge/License-OSL%20v3-yellow.svg)

Application to use BestCord on Android.

## ❓ About

BestCord Manager is an application that installs and updates [BestCord](https://github.com/BestCord-DiscordClient/revenge-bundle),
a modification for Discord.

## 💪 Features

Some of the features BestCord Manager provides are:

- 📲 **Install**: Download Discord and install BestCord on it
- 🔁 **Update**: Update BestCord to the latest version
- 🔔 **Notifications**: Be notified when a new version of BestCord is available
- 📃 **Changelog**: See the changelog of BestCord
